# 📊 Contact Centre Workforce Management & Capacity Planning

An end-to-end analytics project focused on **Workforce Management (WFM)**, contact centre operations, demand analysis and capacity planning.

## 🎯 Business Problem
Contact centres experience fluctuating customer demand throughout the day. Inadequate staffing can increase customer waiting times, reduce service-level performance and affect operational efficiency.

This project uses operational data to analyse call patterns, evaluate workforce capacity and estimate staffing requirements.

## 🔍 Key Analysis
- **Call Volume Analysis:** Identify peak hours, demand patterns and workload trends.
- **Workforce Capacity Planning:** Estimate staffing requirements based on call volume and Average Handle Time (AHT).
- **Service Level Analysis:** Evaluate customer service performance against defined targets.
- **Occupancy & Shrinkage:** Understand workforce utilisation and employee availability.
- **Capacity Gap Analysis:** Identify staffing shortages and potential overcapacity.
- **MIS Reporting:** Consolidate operational KPIs into an interactive Excel dashboard.

## 🛠️ Tools & Technologies
- Python (Pandas, NumPy, Matplotlib)
- SQL
- Microsoft Excel
- Microsoft PowerPoint

## 📈 Key Deliverables
1. Python notebook for data cleaning and exploratory analysis.
2. SQL queries for operational KPI analysis.
3. Excel dashboard for WFM performance and capacity monitoring.
4. PowerPoint presentation summarising business insights and recommendations.

## 💡 Business Objective
To demonstrate how data analytics can support workforce planning, improve resource utilisation, monitor service-level performance and enable data-driven operational decisions.
